## Decision logic (current)

| Condition | Decision |
|-----------|----------|
| mean > go_t | Go |
| hi < kill_t AND no better repurpose | Kill |
| hi < kill_t AND repurpose_pots > mean * 1.2 | Repurpose |
| between thresholds AND repurpose_pots > mean * 1.2 | Repurpose |
| between thresholds, no better repurpose | Continue |

Phase thresholds: Phase I (kill=0.05, go=0.15), Phase II (kill=0.10, go=0.25), Phase III (kill=0.15, go=0.40)

Expected output with default interim data: A=Go, B=Go, C=Continue, D=Continue, E=Go

## What's working

- Beta-Binomial Bayesian PoTS model with prior + interim data updating
- Phase-dependent kill/go thresholds with interactive scale slider
- Correlated failure propagation via correlation matrix
- Biology-driven repurposing with 1.4x safety bonus
- eNPV capital allocation (greedy, budget-constrained)
- Monte Carlo with Gaussian copula (10k sims, reports median)
- ipywidgets interactive explorer in notebook section 10
- All plots saved to plots/ and embedded in README.md
